# 04 · 界面设计

## 交互原则

**1. 键盘流优先，鼠标是备用**

PC 端手录场景，键盘是最快的输入方式。熟练后一笔货应在 3 秒内录完，全程不碰鼠标。传统收银软件坚持 PC + 键盘不是老派，是因为键盘确实最快。

**2. 字号和点击区域比常规大一号**

使用者可能四五十岁。正文不小于 16px，关键数字 32px 起，按钮高度不低于 48px。

**3. 结账不弹对话框**

九成单子是现金。「现金收讫」一键完成，不确认、不选支付方式、不填备注。只有「挂账」才需要多选一个客户。

**部分付（F7）是第三条路径，不得污染前两条** —— 只有主动按下 F7 才会出现金额输入框。九成单子走 F8，这条原则就还站得住。

**4. 核心信息零点击可见**

"谁欠我钱"、"今天赚了多少"必须在打开软件的瞬间就在屏幕上，不需要点任何东西。

**5. 异常是提醒，不是拦路**

库存为负照常记账，只标红提示。绝不阻止老板完成录入。

**6. 改错要像没错过一样简单**

录错是必然事件，不是异常流程。老板点「修改」、改数字、回车，就结束了 —— 系统内部的作废重建对他完全不可见。

界面上**不出现「作废」「红冲」「反向凭证」这类会计词汇**。他要的是"我打错了，改一下"。

## 键盘流

### 卖货主流程

```
焦点默认在搜索框
  ↓ 输入 zhy
下拉出候选「中华(硬)」，↑↓ 可选
  ↓ 回车
选中商品，焦点自动跳到数量框，单位默认「条」（Tab 可切到「包」）
  ↓ 输入 2，回车
加入清单，焦点自动回到搜索框
  ↓ F8
现金收讫，完成，清空清单，焦点回搜索框
```

常用商品支持数字键直选：按 `1` 直接加入 1 号常用商品。

### 快捷键表

| 键 | 功能 |
|---|---|
| `F1` | 卖货 |
| `F2` | 进货 |
| `F3` | 收款 |
| `F4` | 报表 |
| `F7` | 部分付（选客户 + 输已收金额） |
| `F8` | 现金收讫 —— **主路径，九成单子走这里** |
| `F9` | 挂账（弹客户搜索） |
| `Enter` | 在流水列表上：打开单据详情（可改 / 可退货） |
| `Esc` | 取消当前输入 / 返回 |
| `1`–`9` | 快速选择常用商品（搜索框为空时） |
| `↑` `↓` | 在候选列表中移动 |
| `Tab` | 切换单位（条/包、箱/瓶） |

## 页面布局

### 看板（首页）

```
┌──────────────────────────────────────────────────────────────────┐
│ 烟酒台账      F1卖货  F2进货  F3收款  F4报表    备份: 今天 02:00 │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│    今日营业额           今日毛利            本月毛利             │
│     ¥2,480              ¥520               ¥14,300               │
│                                                                  │
├─────────────────────────────────┬────────────────────────────────┤
│  待收欠款  ¥8,200  (3人)        │  需要注意                      │
│  老王     ¥3,200   45天  [收款] │  · 2 个商品库存为负            │
│  李总     ¥4,500   12天  [收款] │    可能漏记进货                │
│  张师傅   ¥  500    3天  [收款] │  · 5 个商品超 90 天未动        │
├─────────────────────────────────┴────────────────────────────────┤
│  今日流水                                                        │
│  14:32   中华(硬)  ×2条                ¥1,100   现金             │
│  13:05   茅台飞天  ×1瓶                ¥1,380   挂账·李总        │
│  11:20   利群      ×1条                ¥  230   现金             │
└──────────────────────────────────────────────────────────────────┘
```

欠款列表**按账龄倒序**，拖得最久的排最前——这才是老板该先打电话的人。

### 卖货

```
┌─────────────────────────────────────────────────────────────────┐
│ ← 卖货                                    业务日期: 2026-09-19  │
├──────────────────────────────┬──────────────────────────────────┤
│  🔍 zhy                      │  已选                            │
│  ┌────────────────────────┐  │  中华(硬)   2条  ¥550   ¥1,100   │
│  │ 中华(硬)  条¥550 包¥57 │  │  利群       1条  ¥230   ¥  230   │
│  │ 中华(软)  条¥700 包¥72 │  │                                  │
│  └────────────────────────┘  │  ─────────────────────────────   │
│                              │  折前               ¥1,330       │
│  常用商品                    │  抹零   [  30 ]                  │
│  1 中华(硬)    2 利群        │  应收               ¥1,300       │
│  3 黄鹤楼      4 茅台飞天    │                                  │
│  5 五粮液      6 青岛啤酒    │  [ F8 现金收讫 ]                 │
│                              │  [ F9 挂账 ]   [ F7 部分付 ]     │
└──────────────────────────────┴──────────────────────────────────┘
```

- 左右分栏，**不跳页**。商品选择和购物车同屏
- 常用商品按近 30 天销量排序取前 12，可手动置顶（`products.sort_weight`）
- 单价可当场改（讨价还价是常态），改价后毛利实时重算
- **业务日期在右上角且可改** —— 补录昨天的单子就改这里
- **抹零框输的是让掉的钱**（输 30 表示少收 30），不是折后总额。老板心里算的是"让了 30"，不是"收 1300"
- **绝不允许靠改单价来抹零** —— 单价一脏，单品利润排行和建议售价就全废了

**关于"预估毛利"**：技术上可以实时显示这单赚多少，但客人可能就站在柜台对面看着屏幕。**默认隐藏**，给一个快捷键切换显示。

### 进货

布局与卖货一致，差异：

- 要选供应商（可空）
- 填的是**进价**不是售价
- 频率低，可以稍慢，允许多步确认
- 录入后立即显示该商品的新加权成本，让老板知道成本变了

### 收款

```
┌─────────────────────────────────────────────────────────────────┐
│ ← 收款                                                          │
├─────────────────────────────────────────────────────────────────┤
│  🔍 搜索客户（拼音）                                            │
│                                                                 │
│  客户          欠款      账龄      最早一笔                     │
│  老王         ¥3,200     45天     2026-08-05      [收款]        │
│  李总         ¥4,500     12天     2026-09-07      [收款]        │
│  张师傅       ¥  500      3天     2026-09-16      [收款]        │
│                                                                 │
│  合计待收     ¥8,200                                            │
│                                                                 │
│  预收（不催收）                                                 │
│  王老板       预收 ¥300                                         │
└─────────────────────────────────────────────────────────────────┘
```

点「收款」→ 输金额 → 选方式 → 回车完成。系统按 FIFO 自动核销，**不让老板选核销哪张单**。按单明细收在客户详情页里，需要时才看。

**收多了照收。** 老王欠 3,200 给了 3,500，那 300 自动成为预收，下次买货抵扣。界面上预收客户灰色显示、排在列表最末、不带「收款」按钮 —— **催收队列里只能有真欠钱的人**，混进预收客户会让这个列表失去可信度。

### 报表

- 日 / 月毛利趋势
- 单品利润排行（按毛利额，可切毛利率）
- 滞销预警：超 N 天未销售且有库存的商品
- 库存金额汇总

**每张报表都要标注「毛利，不含房租水电人工」**，避免被当成净利。

## 视觉规范

| 项 | 值 |
|---|---|
| 正文 | ≥ 16px |
| 关键数字（营业额、毛利、欠款） | ≥ 32px |
| 按钮高度 | ≥ 48px |
| 主操作按钮（现金收讫） | ≥ 64px 高，占满栏宽 |
| 行高 | 宽松，列表行高 ≥ 44px |

配色保持克制：主色一个、警示红一个、其余灰阶。台账软件不需要花哨，需要看得清。
